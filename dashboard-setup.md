# Panduan Setup & Konfigurasi Proyek: Mochi & Lukchup Customizer

Dokumen ini berisi panduan teknis mengenai struktur proyek, teknologi yang digunakan, cara menjalankan aplikasi secara lokal, serta pembagian peran dan tugas tim pengembang.

---

## 1. Teknologi yang Digunakan
* **Antarmuka (Frontend)**: HTML5, CSS3, dan JavaScript (Vanilla JS untuk logika kustomisasi 2D interaktif dan manipulasi DOM).
* **Styling**: Modern CSS (Flexbox/Grid) untuk tata letak responsif pada perangkat seluler maupun desktop.
* **Kontrol Versi**: Git & GitHub (`MPPL01022026/Kelompok-16`).

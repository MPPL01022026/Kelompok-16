# Rencana Sprint & Target Pengembangan: Mochi & Lukchup Customizer

Dokumen ini memuat pembagian tahapan kerja (Sprint) untuk menyelesaikan proyek *Web-Based Interactive 2D Mochi & Lukchup Customizer & Best-Seller Analytics Dashboard* secara terstruktur.

---

## Sprint 1: Perencanaan, Desain, & Kerangka Dasar
* **Fokus Utama**: Penyusunan dokumentasi fase, perancangan antarmuka (UI/UX), dan pembuatan struktur dasar kode HTML/CSS.
* **Target Tugas**:
  * Menyelesaikan dokumen WBS dan Function Point (Selesai).
  * Membuat file dokumentasi `ui-ux-mochi.md` dan `dashboard-setup.md`.
  * Menyusun kerangka halaman utama pada file `index.html`.
* **Tim yang Bertanggung Jawab**: Ocha, Safira, Ain, Latifah.

## Sprint 2: Pengembangan Fitur Interaktif 2D Mochi & Lukchup
* **Fokus Utama**: Implementasi logika kustomisasi produk secara visual dan interaktif menggunakan JavaScript.
* **Target Tugas**:
  * Membangun antarmuka canvas 2D untuk pilihan bentuk, warna, dan isian mochi/lukchup.
  * Mengintegrasikan tombol *Live Preview* agar perubahan kustomisasi langsung terlihat oleh pengguna.
* **Tim yang Bertanggung Jawab**: Ocha, Safira, Ain.

## Sprint 3: Implementasi Analytics Dashboard & Finalisasi
* **Fokus Utama**: Membangun dashboard analitik produk terlaris (*Best-Seller*) dan pengujian akhir sistem web.
* **Target Tugas**:
  * Membuat komponen grafik atau tabel rekapitulasi data penjualan pada halaman web.
  * Melakukan pengujian fitur (*testing*) secara menyeluruh oleh tim.
  * Penyusunan laporan akhir dan *deployment* proyek.
* **Tim yang Bertanggung Jawab**: Ain, Latifah, dan seluruh anggota kelompok.

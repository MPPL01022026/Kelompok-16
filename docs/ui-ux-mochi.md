# Rancangan UI/UX: Web-Based Interactive 2D Mochi & Lukchup Customizer & Best-Seller Analytics Dashboard

Dokumen ini berisi rancangan antarmuka pengguna (UI) dan pengalaman pengguna (UX) untuk proyek pengembangan aplikasi web interaktif *Mochi & Lukchup Customizer* serta *Best-Seller Analytics Dashboard*.

---

## 1. Halaman Utama (Landing Page)
* **Header & Navigasi**: Logo produk, menu (Home, Customizer, Analytics, About Us).
* **Hero Section**: Sambutan hangat dengan visual ilustrasi mochi dan lukchup yang menarik.
* **Call to Action (CTA)**: Tombol utama "Mulai Kustomisasi Sekarang" dan "Lihat Dashboard Penjualan".

## 2. Halaman Customizer 2D Interaktif (`Customizer`)
* **Area Canvas 2D**: Menampilkan visual dasar kue Mochi atau buah/aneka bentuk Lukchup di tengah layar.
* **Panel Kontrol Samping (Sidebar)**:
  * *Pilihan Basis/Kulit Mochi*: Pemilihan warna dan tekstur (misal: original, pandan, stroberi).
  * *Pilihan Isian (Filling)*: Opsi isian seperti cokelat, kacang merah, matcha, dll.
  * *Pilihan Topping & Hiasan*: Menambahkan dekorasi di atas mochi atau lukchup.
* **Fitur Pratinjau (Live Preview)**: Perubahan visual langsung tampil secara *real-time* di canvas 2D saat pengguna memilih opsi.
* **Tombol Aksi**: Tombol "Simpan Kustomisasi" dan "Pesan Sekarang".

## 3. Halaman Dashboard Analitik Penjualan (`Analytics Dashboard`)
* **Ringkasan Metrik (Cards)**: Total pesanan, pendapatan harian/bulanan, dan item terlaris (*Best-Seller*).
* **Grafik Visualisasi Data**:
  * Grafik batang (Bar Chart) untuk produk Mochi dan Lukchup yang paling banyak diminati.
  * Diagram lingkaran (Pie Chart) persentase kombinasi isian favorit pelanggan.
* **Tabel Riwayat Pesanan**: Menampilkan data pesanan kustomisasi terbaru dari pembeli.
